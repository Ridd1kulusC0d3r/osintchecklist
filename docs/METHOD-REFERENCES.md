# Method References

The method uses several bodies of tradecraft as references rather than cloning one framework.

## Berkeley Protocol on Digital Open Source Investigations

OHCHR and the Human Rights Center at UC Berkeley describe professional standards for identifying, collecting, preserving, analysing and presenting digital open-source information, with attention to legality, ethics and safety.

https://www.ohchr.org/sites/default/files/2022-04/OHCHR_BerkeleyProtocol.pdf

## ICD 203 — Analytic Standards

ODNI's directive emphasizes source quality, uncertainty, separation of underlying information from assumptions and judgments, analysis of alternatives, relevance to the customer, logical argumentation and material contrary information.

https://www.dni.gov/files/documents/ICD/ICD-203.pdf

## NATO AJP-2

AJP-2 describes evaluating source reliability and information credibility independently.

The workbench makes this rating optional because not every investigation has enough information to justify a formal code.

## Bellingcat

Bellingcat's published methodology and tool guidance reinforce several practical ideas used here:

- retain original sourcing;
- understand tool limitations;
- corroborate important claims;
- make investigation methods reproducible;
- consider ethical implications.

https://www.bellingcat.com/resources/2024/09/24/bellingcat-online-investigations-toolkit/

https://www.bellingcat.com/resources/2024/04/25/oshit-seven-deadly-sins-of-bad-open-source-research/

## ATP 2-22.9

The U.S. Army publication is a useful historical reference for OSINT as an intelligence discipline and for collection planning. It is older and should not be treated as a current universal standard.

## Design consequence

These references pushed the checklist away from:

```text
find data → add data → find more data
```

and toward:

```text
define decision
→ define requirement
→ plan collection
→ collect proportionately
→ evaluate sources
→ preserve evidence
→ compare hypotheses
→ test contrary evidence
→ calibrate confidence
→ decide whether to stop
→ report
→ learn
```
