# Analyst Decision Flow

O checklist não foi ordenado para “fazer tudo”. Ele foi ordenado para **reduzir incerteza até uma decisão**.

```text
DEMANDA
  ↓
1. DIREÇÃO
   requisito → escopo → baseline → plano
  ↓  Gate A: sabemos o que precisamos descobrir?
2. COLETA
   busca → SOCMINT → identificadores → registros → infraestrutura → mídia/GEOINT
  ↓  Gate B: temos fontes e pivôs suficientes para testar as hipóteses?
3. CORROBORAÇÃO & SÍNTESE
   timeline → avaliação de fontes → evidência → hipóteses concorrentes
  ↓  Gate C: o julgamento é sustentado e as alternativas foram testadas?
4. ANÁLISE & DECISÃO
   respostas → confiança → lacunas → implicações
  ↓  Gate D: parar, coletar mais, monitorar ou escalar?
5. ENTREGA & APRENDIZADO
   relatório → revisão → retenção → lições aprendidas
```

## Gate A — Direção suficiente

Avance quando:

- a pergunta central é específica;
- o decisor e o uso do produto são conhecidos;
- o escopo e os limites de coleta são claros;
- os principais pressupostos estão visíveis;
- existe um plano inicial de fontes e pivôs.

Se isso não existe, mais coleta tende a gerar volume, não inteligência.

## Gate B — Cobertura suficiente

Antes de aprofundar uma linha, pergunte:

- esta fonte é nova ou só repete outra?
- o pivô possui força suficiente para justificar a próxima associação?
- há uma fonte mais primária ou mais próxima?
- o dado é atual para o período que importa?
- qual busca reduziria mais incerteza agora?

## Gate C — Suficiência analítica

Um julgamento material deve ter:

- evidência rastreável;
- qualidade de fonte avaliada;
- contradições consideradas;
- pelo menos uma alternativa plausível testada quando houver incerteza material;
- confiança coerente com qualidade, quantidade e lacunas.

## Gate D — Tomada de decisão

Escolha conscientemente uma saída:

| Saída | Quando usar |
|---|---|
| **Concluir** | A pergunta foi respondida com sustentação suficiente. |
| **Coletar mais** | Existe uma lacuna material e uma coleta plausível pode resolvê-la. |
| **Monitorar** | A decisão depende de condição futura ou mudança observável. |
| **Escalar** | É necessário conhecimento, autorização ou capacidade fora do escopo atual. |
| **Encerrar inconclusivo** | A lacuna é material, mas não há coleta proporcional capaz de resolvê-la. |

O método considera **“não foi possível concluir”** uma saída válida quando ela descreve corretamente a evidência disponível.
