# Source Evaluation

The workbench separates two questions that analysts frequently collapse into one:

1. **How reliable is the source?**
2. **How credible is this specific information?**

A source with a strong track record can still provide incorrect information. A weak or unknown source can occasionally provide information later corroborated as true.

## Reliability of the source

The workbench offers an optional A–F scale inspired by the evaluation model described in NATO AJP-2:

| Code | Workbench label |
|---|---|
| A | Reliable |
| B | Usually reliable |
| C | Fairly / moderately reliable |
| D | Not usually reliable |
| E | Unreliable |
| F | Cannot be judged |
| NA | Not assessed |

## Credibility of the information

| Code | Workbench label |
|---|---|
| 1 | Confirmed |
| 2 | Probably true |
| 3 | Possibly true |
| 4 | Doubtful |
| 5 | Improbable |
| 6 | Cannot be judged |
| NA | Not assessed |

## Do not mechanically score

The code is a compact record of an analytical evaluation, not mathematics.

Before assigning it, ask:

- Did the source have access to the information?
- Is the source primary, derivative or merely an aggregator?
- Is the information current for the relevant time period?
- Do apparently independent sources actually share one origin?
- Is there material contrary information?
- What limitations affect the collection method?

## Independence matters

Five websites can still represent **one information chain** if all repeat the same original claim.

Corroboration becomes stronger when genuinely independent sources or different evidence types converge.

## Confidence is separate

Source evaluation is not the same as confidence in an analytic judgment.

Judgment confidence should consider, among other things:

- quality of evidence;
- quantity of relevant evidence;
- independence;
- information gaps;
- contrary evidence;
- assumptions;
- plausibility of alternatives.
