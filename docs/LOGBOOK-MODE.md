# Modo Diário de Bordo

O **Modo Diário de Bordo** é a versão reduzida do Analyst Workbench.

Ele existe para cenários em que o analista precisa de velocidade e disciplina, mas não quer preencher observação, fonte e objeto analítico em cada linha.

## Como funciona

No modo rápido:

- o checklist fica visualmente reduzido;
- o analista marca a ação executada;
- cada mudança de estado gera automaticamente uma entrada com timestamp no diário;
- observações gerais entram como **nota rápida**;
- o histórico pode ser exportado em Markdown;
- o mesmo caso pode ser alternado para **Workbench completo** sem perder o progresso.

## Quando usar

Use o Diário de Bordo para:

- triagem;
- primeira passada de investigação;
- acompanhamento operacional;
- revisão de rotina;
- investigação de baixo risco e baixa complexidade;
- treinamento inicial do método.

Use o Workbench Completo quando houver:

- evidências materiais que precisam de rastreabilidade;
- múltiplas entidades;
- relações que precisam ser qualificadas;
- timeline relevante;
- julgamentos analíticos;
- necessidade de revisão por outro analista;
- entrega executiva ou técnica.

## O princípio

O modo simples registra principalmente **o que foi feito e quando**.

O modo completo registra:

```text
ação
+ resultado
+ fonte
+ evidência
+ entidade
+ relação
+ tempo
+ julgamento
+ confiança
```

Não são dois métodos diferentes. São dois níveis de documentação do mesmo método.
